How to add a blog post
======================

1. Copy one of the .md files in this folder and rename it, for example `my-new-post.md`.
   The file name becomes the address: digitallineup.com/blog/my-new-post/
2. Edit the header between the --- lines: title, description (under 160 characters), date (YYYY-MM-DD),
   cover (an image path, 1200x675 works best), cover_alt, tags.
3. Write the article below the header in plain Markdown. Use "## Quick answers" with "### Question?" lines
   to get the green answer boxes (Google reads these as FAQs).
4. Commit. The site rebuilds and publishes by itself in about a minute.

Add `draft: yes` to the header to keep a post hidden.
